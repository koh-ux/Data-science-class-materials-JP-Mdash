# Data-science-class-materials-JP-Mdash
class materials for the information technology literacy @ JP kosen 1st year. And some supplement for other college and universities. 

# 高専向け MDASH カリキュラム 授業資料リポジトリ

本リポジトリは、高専1年生を対象とした数理・データサイエンス・AI（MDASH）教育のための授業案、スライド、およびサンプルコードを公開しています。

## フォルダ構成

本リポジトリは、標準的なカリキュラム（Core）と、より高度・専門的な内容（suppl）に分かれています。

### 1. Core: 高専1年生向け標準カリキュラム
高専1年生の導入教育に最適化された内容です。
- `Core/Codes/`: 授業でそのまま使える、またはライブコーディング用のコード
- `Core/Documents/`: 授業用スライド（PDF/Markdown）、ワークシート、授業案

### 2. suppl: 発展・専門内容
大学生以上や、より深く学びたい学生・専攻科向けの資料です。
- `suppl/DS/`: データサイエンス（認知心理学、コネクトドッツ、探求学習等）
- `suppl/Inst/`: 計測工学（古典統計学、標準、センシング等）
- `suppl/PM/`: プロジェクトマネジメント（ケーススタディ、ワークショップ形式）

### 3. meta: 制作プロセス・ログ
教材作成の背景や、AIとの共創プロセスを記録しています。
- `meta/AI_logs/`: スライド構成やコード生成時のAI（Gemini/ChatGPT）との対話記録
- `meta/notes/`: 授業設計の意図、試行錯誤の記録、ちょっとした裏話（駄文）

> **Note:** AIとの対話ログを含めることで、生成AIを教育準備にどう活用できるかの知見を共有することを目指しています。

## 使い方（教員の皆様へ）

本教材を活用いただくにあたって、以下の点をご確認ください。

* **スライド資料について**
    * 各フォルダに **PDF** と **Googleスライドのコピー用リンク** を用意しています。
    * 授業の進度や学生の反応に合わせて、自由に改変してご活用ください。
* **実行環境**
    * サンプルコードは `Jupyter Notebook (.ipynb)` 形式です。
    * 原則として **Google Colaboratory** での利用を前提としています。
    * 低学年等でクラウド環境が利用できない場合は、WSL等のローカル環境を整備して実行してください。
