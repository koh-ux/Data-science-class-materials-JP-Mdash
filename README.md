# 高専向け MDASH カリキュラム 授業資料 (Class Materials)

本リポジトリは、高専1年生を対象とした数理・データサイエンス・AI（MDASH）教育のための授業案、スライド、およびサンプルコードを公開しています。

## フォルダ構成

- **Core: 高専1年用**
  - `Codes/`: サンプルコード（主にJupyter Notebook）
  - `Documents/`: 授業用スライド（PDF/Googleスライド）
- **suppl: 発展用**
  - `DS/`: データサイエンス/認知心理学・コネクトドッツ・研究・探究（大学生以上推奨）
  - `Inst/`: 計測工学/古典統計＋標準
  - `PM/`: プロジェクトマネジメント/Case study, Work 等
- **meta: 制作プロセス**
  - AIとの対話ログ、設計思想、試行錯誤の記録（駄文）

## 使い方（教員の皆様へ）

* **スライド資料**
  - GoogleスライドのリンクとPDFを同梱しています。
  - 編集したい場合は、Googleスライドのコピーを作成して自由にご利用ください。
* **コード環境**
  - Jupyter Notebook (.ipynb) 形式です。**Google Colaboratory** 利用を前提としています。
  - 低学年等でクラウド環境が利用できない場合は、WSL等のローカル環境を整備してください。
* **設計思想**
  - 本授業案は、ハウツーの習得や理論の暗記を目的としたものではありません。
  - **「学生が専門分野にDSを適用するために、AIを含めて使い倒す」** ことを前提とした実践的な資料です。
